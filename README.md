Journey Couple 

Sebuah jurnal cinta digital dan *memory vault* interaktif dengan estetika editorial modern, hangat, dan elegan.

---

## ✨ Fitur Utama

- **Hero Cover & Live Counter**: Penghitung waktu dinamis (*days, hours, minutes, seconds*) sejak tanggal jadian **20 September 2026**.
- **Our Little Universe (Profil Pasangan)**: Profil kepribadian & detail manis dari **Araf** dan **Nicky**.
- **Spotify Official Player**: Pemutar musik *"Until I Found You"* oleh Stephen Sanchez yang terintegrasi langsung tanpa jeda.
- **Chapters We Cherish (Milestones)**: Kumpulan babak kisah cinta mulai dari masa magang, perjalanan ke Bali, kulineran ramen di RamenYA! Tasikmalaya, hingga *bucket list* masa depan.
- **Polaroid Keepsakes (Editorial Collage)**: Kolase seni polaroid berlapis terinspirasi poster visual editorial dengan tipografi mesin tik *scattered pixel*.
- **Interactive Memories Vault**: Galeri pop-up album kenangan foto berdua.
- **Love Shower Animation**: Animasi interaktif partikel hati saat tombol diklik.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & Vanilla JavaScript**: Struktur semantik dan logika interaktif tanpa ketergantungan framework berat.
- **Tailwind CSS (CDN)**: Desain responsif dengan palet warna hangat (*Ivory, Sand, Terracotta, Sage, Charcoal*).
- **Google Fonts**:
  - *Cormorant Garamond* & *Playfair Display* (Editorial Serif)
  - *Plus Jakarta Sans* (Body Text)
  - *Alex Brush* (Calligraphy Script)
  - *VT323* (Pixel Typewriter)
- **Lucide Icons**: Ikonografi minimalis dan bersih.

---

## 🚀 Menjalankan Secara Lokal

Cukup buka berkas `index.html` langsung di browser, atau gunakan web server lokal:

```bash
# Menggunakan npx serve
npx serve .

# Atau menggunakan Python
python -m http.server 3000
```

Buka peramban di `http://localhost:3000`.
